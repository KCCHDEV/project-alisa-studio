NATIVE PTY ENGINE

High-Speed Native Shell Terminal

เทอร์มินัลจริงที่เชื่อมต่อกับ PTY ของระบบโดยตรง รันคำสั่ง Bash / Zsh / PowerShell ได้เต็มประสิทธิภาพ พร้อมรองรับ Session แยกระหว่าง Local และ SSH

  • Zero-Lag Output: ถ่ายทอดผลลัพธ์คำสั่งแบบเรียลไทม์ผ่าน WebSocket ความเร็วสูง
  • Quick Interruption (Ctrl+C): สั่งหยุดกระบวนการที่รันค้างอยู่ได้ทันทีผ่านปุ่ม Stop หรือคีย์บอร์ด
  • Agent Command Audit: มองเห็นทุกคำสั่งที่ AI นำไปรันอย่างโปร่งใส
TECH ARCHITECTURE

สถาปัตยกรรม & ภาพรวมของระบบ

สร้างบนพื้นฐานเทคโนโลยีที่ทันสมัยที่สุด ไร้ความเทอะทะของ Electron

🦀

Tauri v2 + Rust

แกนหลักของเดสก์ท็อปแอปเขียนด้วยภาษา Rust กินหน่วยความจำน้อยกว่า Electron ถึง 4 เท่า สตาร์ทโปรแกรมไว และมีความปลอดภัยสูง

⚡

Bun HTTP/WS Server

เซิร์ฟเวอร์แบ็กเอนด์เฉพาะที่รันบน Bun Runtime จัดการ WebSocket, การอ่านเขียนไฟล์ และการรัน Shell PTY Terminal ด้วยความเร็วระดับ C++

🔄

OmniRoute Zero-Stall

เกตเวย์เชื่อมต่อโมเดล LLM พร้อม Inactivity Watchdog 25 วินาที และ Smart Exponential Backoff หมดปัญหาแอปค้างหรือนิ่งไปเฉยๆ

🎵

Procedural Web Audio

ระบบเสียงเอฟเฟกต์สังเคราะห์ความถี่เสียงด้วยโค้ด Pure Web Audio API ทำงานออฟไลน์ 100% โดยไม่ต้องโหลดไฟล์ mp3 หรือ wav ภายนอก

เราเชื่อในความโปร่งใส นี่คือสิ่งที่คุณควรรู้ก่อนใช้งานจริง

🧠

การเลือกใช้ AI Model ให้คุ้มที่สุด

สเปกเครื่องและความเป็นจริง

ตัวแอป Alisa ใช้ RAM เพียง 150-300MB เท่านั้น แต่เนื่องจากต้องรันโปรเจกต์ของคุณเอง (เช่น node_modules, vite dev server, compiler) จึงแนะนำให้มี RAM ขั้นต่ำ 8GB และแนะนำ 16GB สำหรับการรันหลายโปรเจกต์พร้อมกัน

#HardwareRequirements
🛡️

ความจริงเรื่อง Unsigned Binary

เนื่องจาก Alisa Studio เป็นโปรเจกต์โอเพนซอร์สฟรี เราไม่ได้จ่ายค่าธรรมเนียม $99/ปี ให้ Apple หรือ $400/ปี ให้ Microsoft สำหรับใบรับรององค์กร ทำให้ macOS อาจขึ้นเตือน "Unidentified Developer" (กดคลิกขวา > Open ได้เลย) และ Windows อาจขึ้น "SmartScreen" (กด More info > Run anyway) มั่นใจได้ว่าโค้ดทั้งหมดเปิดเผยและปลอดภัย 100%

#Gatekeeper #SmartScreen
⚖️

เมื่อไหร่ควรใช้ Alisa vs VSCode?

ถ้าคุณต้องการนั่งเคาะพิมพ์โค้ดเองทีละบรรทัด VSCode อาจตอบโจทย์กว่า แต่ถ้าคุณต้องการ Autonomous Flow ที่คุณสั่งงานเป้าหมายระดับสูง แล้วปล่อยให้ Agent Swarm คิด วางแผน แก้ไข รันเทอร์มินัล และรีวิวให้เบ็ดเสร็จ Alisa Studio จะช่วยประหยัดเวลาของคุณได้มหาศาล

QUESTIONS & ANSWERS

คำถามที่พบบ่อย (FAQ)

รวมทุกข้อสงสัยเกี่ยวกับการติดตั้งและการใช้งาน

โปรแกรมนี้ฟรีจริงไหม มีค่าใช้จ่ายแอบแฝงหรือไม่? ▾
ฟรีและเป็นโอเพนซอร์ส 100% ภายใต้สัญญาอนุญาต MIT คุณสามารถดาวน์โหลดไปใช้งาน ปรับแต่ง หรือศึกษาโค้ดได้ตามต้องการ ค่าใช้จ่ายเพียงอย่างเดียวที่คุณอาจมีคือค่า Token ของ API โมเดล AI ที่คุณเลือกนำมาเชื่อมต่อ (เช่น Google AI Studio, OpenAI หรือ OmniRoute) หรือหากใช้ Ollama/Local LLM ในเครื่องตัวเองก็จะฟรีทั้งหมดครับ
บน macOS เปิดโปรแกรมไม่ได้ ขึ้นฟ้องว่าไม่สามารถตรวจสอบความปลอดภัยได้? ▾
เนื่องจากเรายังไม่ได้จ่ายค่าใบรับรององค์กรรายปีของ Apple ระบบ Gatekeeper จึงจะแจ้งเตือนเมื่อเปิดครั้งแรก ให้ทำดังนี้: คลิกขวาที่ตัวแอป Project Alisa Studio V2 > เลือก Open > กดยืนยัน Open หรือไปที่ System Settings > Privacy & Security > กด "Open Anyway" ครั้งเดียวก็เปิดใช้งานได้ตลอดไปครับ
บน Windows ทำไม Windows Defender หรือ SmartScreen ถึงแจ้งเตือน? ▾
ตัวติดตั้ง .exe สร้างขึ้นด้วย NSIS ที่คอมไพล์ใหม่สดๆ จากซอร์สโค้ด จึงยังไม่มีคะแนนชื่อเสียงในฐานข้อมูลของ Microsoft SmartScreen ให้กดปุ่ม "More info" (ข้อมูลเพิ่มเติม) > แล้วกดปุ่ม "Run anyway" (เรียกใช้ต่อไป) ก็จะสามารถติดตั้งได้ตามปกติครับ
เสียงเอฟเฟกต์น่ารักมาก แต่ถ้าต้องการปิดหรือปรับระดับเสียง ทำได้ที่ไหน? ▾
สามารถกดไอคอนลำโพงที่มุมขวาบนของแผง Inspector ด้านขวา หรือเข้าไปที่เมนูการตั้งค่า (Settings) จะมีแถบเลื่อนปรับระดับเสียง (Volume Slider) ตั้งแต่ 0% ถึง 100% และปุ่มทดสอบเสียง ซึ่งระบบจะจดจำค่าไว้ตลอดการใช้งานครับ
