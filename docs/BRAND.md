## Character direction

Mascot ของ Project Alisa Studio ควรเป็นตัวแทนของคำว่า **cute developer tool** มากกว่าแค่ anime decoration

บุคลิกหลัก:

- calm
- creative
- slightly shy
- reliable
- technical
- friendly

Visual traits หลัก:

- long silver / lilac hair
- soft blue eyes
- pink + blue X hair clip
- white headphones
- oversized black tech hoodie
- pink / light-blue accents
- small cat motifs
- modern streetwear sneakers
- pastel cyber / studio atmosphere

Mascot ควรน่ารัก แต่ยังทำให้ Project Alisa Studio ดูเป็น developer tool ที่จริงจังได้

| Name | Hex | Use |

| Yurachi Blue | `#86B3FF` | focus / active state |
| Yurachi Violet | `#BBA7FF` | secondary accent |
| Hairline | `#AEBCE2` | low-opacity separators |

---

## Character placement rules

ใช้ character art ใน:

- GitHub README
- welcome screen
- empty states
- About page
- social / release artwork
- documentation cover

หลีกเลี่ยง character art ขนาดใหญ่ด้านหลัง:

- source code
- terminal output
- diff viewer
- error logs
- dense settings

Coding surface ต้องอ่านง่ายเป็นอันดับแรก

---

## UI personality

Project Alisa Studio ควรให้ความรู้สึก:

```text
quiet
compact
soft
modern
technical
personal
```

ไม่ควรเป็น:

```text
neon-heavy cyberpunk
childish UI
huge glowing buttons
anime image everywhere
busy gradients behind code
```

---

## Copy / tone

ใช้ภาษาสั้น อ่านง่าย เป็นมิตร และไม่ corporate เกินไป

ตัวอย่าง:

```text
Ready to work ✦
Open a project and give Alisa a goal.

Thinking…
Reading 3 files
Running tests
Completed
```

Tagline:

> **AI / Code / Create / Automate — together.**

Japanese-style brand line:

> **「好きなことで、もっと先の未来へ。」**

English closing line:

> **Code softly. Build seriously. ✦**

## Repository presentation

README ควรเรียงเนื้อหาตามนี้:

```text
Mascot / logo
Project name + tagline
Badges
Short explanation
Features
Workflow
OmniRoute
Run / setup
Architecture
Roadmap
Security
Brand footer
```

ไม่ควรเริ่ม README ด้วย wall of text หรือ screenshot ของ app ขนาดใหญ่ทันที
